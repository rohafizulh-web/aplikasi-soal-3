Koneksi backend AI

Endpoint backend harus menerima POST JSON dan mengembalikan JSON berisi array questions. Format tiap soal: type, level, question, options (opsional), answer, explanation (opsional), indicator (opsional).
Keamanan penting: jangan masukkan API key langsung di halaman ini. API key harus disimpan di server/backend yang Anda kendalikan. Prototipe ini belum menyediakan server AI bawaan.
